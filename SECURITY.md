# Política de seguridad

Los cambios de seguridad se preparan sobre `beta`; las correcciones aplicables
a la versión estable se revisan también para `main`. El proyecto no ofrece por
ahora un compromiso de soporte de versiones antiguas.

Usa [Report a vulnerability](https://github.com/Duna-tools/cbrec/security/advisories/new)
para comunicar una vulnerabilidad de forma privada. No publiques cookies,
credenciales, URLs HLS firmadas, grabaciones ni información personal en issues.

Incluye la versión o commit, plataforma, pasos reproducibles con datos sintéticos
y el impacto observado. Distingue lo comprobado de las hipótesis. No se promete
un plazo fijo de respuesta; evita pruebas que afecten cuentas o servicios ajenos.
